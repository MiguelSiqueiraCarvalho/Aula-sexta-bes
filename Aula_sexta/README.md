# Sistema de Gerenciamento de Notas de Alunos

## Sobre o projeto

Este projeto consiste em um sistema desenvolvido em Python para gerenciar as notas de alunos de uma faculdade. O programa permite cadastrar estudantes, registrar notas, calcular médias e consultar a situação acadêmica de cada aluno.

O objetivo é aplicar conceitos fundamentais da linguagem Python por meio de um projeto prático.

## Funcionalidades

- **Cadastrar aluno:** registra nome, matrícula e três notas.
- **Listar alunos:** exibe todos os alunos cadastrados.
- **Consultar aluno:** apresenta as notas, média e situação acadêmica de um estudante.
- **Excluir aluno:** remove um aluno pelo número de matrícula.
- **Calcular média:** realiza automaticamente o cálculo da média das três notas.
- **Verificar situação:** identifica se o aluno foi aprovado ou reprovado.

## Tecnologias utilizadas

- Python 3
- Listas
- Dicionários
- Funções
- Estruturas condicionais
- Estruturas de repetição

## Critério de aprovação

O sistema utiliza a média aritmética das três notas:

- Média igual ou superior a 7,0: **Aprovado**.
- Média inferior a 7,0: **Reprovado**.

## Como executar

1. Certifique-se de ter o Python 3 instalado.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute o seguinte comando:

```bash
python3 main.py
```

## Observação

Os dados dos alunos são armazenados temporariamente na memória durante a execução do programa. Ao encerrar o sistema, os registros são perdidos.
